# Pine × Groot 会议详细复盘网页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成一个可离线打开、适配桌面和移动端的 Pine × Groot 会议详细复盘网页。

**Architecture:** 产物使用单页静态 HTML，正文、视觉状态与可访问性语义放在 HTML/CSS 中；仅将 ECharts 初始化放在独立 JavaScript 文件，并将图表库复制到交付目录中。会议事实来自本地逐字稿，使用结构测试保证关键章节、流程图和离线资源没有遗漏，再使用浏览器实际渲染验证。

**Tech Stack:** HTML5、CSS、ECharts、Mermaid、Node.js 内置测试运行器、浏览器验证。

---

## 文件结构

- `deliverables/pine-groot-meeting-review/pine-groot-meeting-review.html`：复盘正文、样式、目录、Mermaid 流程图和本地资源引用。
- `deliverables/pine-groot-meeting-review/assets/charts.js`：能力成熟度矩阵图和自适应尺寸逻辑。

- `tests/artifacts/test_pine_groot_meeting_review.mjs`：验证网页结构、离线依赖、会议事实和图表脚本引用。

```javascript
import assert from "node:assert/strict";
import fs from "node:fs";
import path from "node:path";
import test from "node:test";

const root = path.resolve("deliverables/pine-groot-meeting-review");
const htmlPath = path.join(root, "pine-groot-meeting-review.html");

test("会议复盘网页包含完整章节与离线可视化资源", () => {
  const html = fs.readFileSync(htmlPath, "utf8");
  for (const text of [
    "聊下 Groot 支持 Pine",
    "执行摘要",
    "业务背景",
    "异动归因",
    "预算分配",
    "素材自动化",
    "实时数据与自动调控",
    "行动清单",
    "风险与假设",
    "会议脉络",
  ]) {
    assert.match(html, new RegExp(text));
  }
  assert.match(html, /src="\.\/_shared\/js\/echarts\.min\.js"/);
  assert.match(html, /src="\.\/_shared\/js\/mermaid\.min\.js"/);
  assert.match(html, /src="assets\/charts\.js"/);
  assert.match(html, /<pre class="mermaid">/);
  assert.ok(fs.existsSync(path.join(root, "_shared/js/echarts.min.js")));
  assert.ok(fs.existsSync(path.join(root, "_shared/js/mermaid.min.js")));
});
```
